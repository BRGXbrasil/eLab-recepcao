# E.Lab · Módulo Recepção

Módulo independente do Hub E.Lab.

## Escopo

Agenda, Lista da Vez, confirmações, ocorrências, demandas não atendidas e pós-atendimento.

## Independência

Este repositório possui sua própria interface e armazenamento do módulo. A integração com o Hub principal é feita por um link de acesso; dados operacionais não são compartilhados automaticamente com os outros módulos.

## Próximas evoluções

- autenticação por perfil;
- persistência central no banco do módulo;
- histórico por data e responsável;
- indicadores operacionais;
- publicação como módulo acessível pelo Hub E.Lab.
